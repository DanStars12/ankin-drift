# 全6機体の通しAI比較と戦闘調整（2026-11-17）

基点はmain a51235c。SHOT/LASER/CHARGE/DRILL/DOG/PHANTOMを通常30分・チャレンジ15分で各20シード（17〜36）ずつ測る。PHANTOMは既存の先読み回避操縦を使用。実際の敵・経験値・報酬・合成・被弾・最終ボス進行を使い、無敵やHP補充で結果を良くしない。

## 評価AIの修正と対照

LASER/CHARGE/DRILL/DOGの報酬評価が会心を評価していなかった。DRILLは基本攻撃力による接触0.34倍・突進1.35倍の寄与も落としていた。これらを修正し、CHARGE操縦は満充電を検知したら停止を終えて解放するようにする。両ゲーム版に**同じ最終AI**を適用し、ゲーム本体の強化とAI改善を混同しない。

会心/DRILL評価修正だけを先に同じゲーム2群で計測した対照では、全240試行の結果が両群で一致した。CHARGEの満充電解放修正前の値は次のとおり。原データ: `docs/qa/all-six-evaluation-control-20261117.json`。

## 調整する挙動

- LASER: ビーム3本までは同じ。4本目以降の出力逓減係数を0.045→0.025にし、多ビーム育成の伸びを改善。弾・ビームの本数上限と威力の逓減式は維持する。
- CHARGE: 基本蓄電速度0.67→0.74。静止して溜め、移動で放つ仕組みは維持。AIにも実際の満充電を使わせる。
- DRILL: 初期シールド30・再充填2/秒を追加。敵本体の体当たりを25%軽減する。弾・地雷・レーザー等にはこの接触軽減を適用せず、ダッシュとNOVAの無敵は従来どおり。機体説明と数値表示も更新。
- DOG: 骨追加カードの1発威力低下を8%→5%へ。通常骨の拡散を0.22→0.18radにし、大型単体へ攻撃をまとめやすくする。Lv20/10分以降の「ほねっこ・おかえり練習」は帰還威力/速度に加え、発射間隔-6%（最短0.65秒）。初期発射間隔と骨数上限8本、NOVAの8方向配置は維持する。
- PHANTOM: 共通の保護シールド・反応装甲・EXP装甲・修理・NOVA系の実在IDが許可リストから漏れていた点を修正。選択による自己防衛を育てられるようにする。通常ショット等の機体不適合なカードは除外し、主機・ダーツの数や基本攻撃速度を増やさない。
- SHOTはゲーム本体の性能を変えず、同じシード比較の対照とする。

## 検証の読み方

既存の通し比較CIをPHANTOM込み6機体に拡張。各分のHP/シールド/Lv/累積ダメージ/ボス距離を記録する。死亡で止まった試行も20回の分母に含める。最終ボス到達と撃破、時間切れを分け、短時間ボス試験をクリア数に含めない。

機体差には検証AIの操作・育成判断も含まれる。20シードの数値を人間の勝率とはみなさない。調整版/基準版は同じAIで比較し、両モードのクリア数と死亡時刻を確認する。最終の比較表・実行コミット・workflowは[PR #89](https://github.com/DanStars12/ankin-drift/pull/89)に記録する。

回帰は実際の敵接触の軽減と弾の非軽減、通常骨8本の単体集中命中、PHANTOMの防御カード抽選/経験値回復、満充電検知によるAI解放を確認する。従来のPC/スマホ、最大5ファントム+25ダーツ+235敵、複合レイド/ボス戦1倍/2倍、構文・PWA・セーブの検証も実行対象。
