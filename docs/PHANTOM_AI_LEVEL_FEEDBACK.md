# ダーツAIとレベルアップ表示

攻撃型ダーツは個別の出撃位置・射撃待機、機体ごとに異なる周回接近点、味方間の分離、標的の混雑補正を使う。レリック優先を維持し、攻撃の射程・壁判定を変えずに重なりを避ける。

フォロー型はフィールド外の到達不能な経験値を追わない。標的変更で古い経路を破棄し、0.65秒以上接近できない対象は最大6件・4秒の一時除外にして他の経験値を探す。ワープせず、通常の壁判定と速度を使う。回復アイテムは拾わず、経験値は出撃終了時に届ける。

ファントム上限をLv30に変更。コア20回・リミットブレイク8回まで成長可能にし、Lv30で出現停止。Lv11以降の攻撃・速度等の係数成長は従来の35%に抑え、HP/シールドの成長と上限後の小さな変換を維持する。Lv10でのゴーストブレード強化はLv10以上で維持。

実際にレベルが上がると、各ファントム本体の上にLEVEL UPとLvを2秒表示。上部のシナジー通知欄にも5秒表示し、ビルド再構築だけでは再通知しない。通常のレベルアップには機体周囲のリングと文字、カードの登場演出を追加。動きを減らす設定では登場アニメーションを抑制する。

スマホの新しいカードは700msの保護期間後に新しいタップで選択し、別の取得ボタンで確定する。タップだけでは取得せず、選択から180ms以内の確認も無効。再抽選・連続強化時は選択をリセット。キーボードとPADの明示的な決定操作は維持する。
