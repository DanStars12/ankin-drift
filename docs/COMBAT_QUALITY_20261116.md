# 戦闘品質・機体補正の修正（2026-11-16）

基点は main ef5c79f。通常モードの実ゲームを固定1/60秒で動かし、同じAI・乱数・武装プリセットで比較した。描画なしの計測を実機FPSや人間の勝率とは扱わない。

## 実装

- CHARGE：弾の枠が満杯なら、蓄えた彗星を消費せず発射待ちにする。移動・回避を続けられ、枠が空けば一度だけ発射する。待機を停止姿勢と区別し、移動中に蓄電姿勢の防御を得ない。停止すれば再蓄電できる。失敗時には追撃彗星・最大解放の回生・演出・属性サイクルを消費しない。NOVAは従来の専用枠確保で発射する。
- CHARGE：ビルド再計算で発射待ち状態と生存中の追撃彗星キューを保持する。再計算による消失や二重発射を防ぐ。
- DRILL：通常の接触攻撃にもボス特効を一度適用する。従来は突進だけが対応し、オーバーロード等の「ボスへの基本攻撃ダメージ」が接触には反映されなかった。NOVAの威力計算は独立させる。
- DOG：帰還威力を通常骨の命中ダメージにまとめ、会心・ボス特効・ガード補正を全体に一度適用する。従来は追加分を補正前の威力で別計算していた。二重命中処理も省く。NOVA骨は通常骨専用補正を受けない。

機体の基礎HP・移動速度・威力・発射間隔、敵能力、PHANTOMの索敵間隔と演出軽量化は維持。性能調整は説明どおり働かなかった条件付き補正を直す範囲に絞った。

## AI比較

旧版/修正版それぞれ、6機体×初期/育成済み×集団/ボス×3シード＝72条件、各最大45秒。死亡・ボス撃破で終了する。育成済みは10分敵スケールのプリセットで、機体ごとの装備コストを一致させたビルドではない。特にドリルは前方を向けないAI操作の影響があるため、機体間のDPS差から一律の強化量を決めない。

DRILLは+11.26%だが、この条件の生存は改善していない。残り23グループの平均結果は同じ。DOGの会心/帰還強化やCHARGEの弾枠飽和は、この通常プリセットでは発生せず、専用の不具合再現テストで確認した。

自然育成は6機体×3シード×120秒を両版で比較し、18/18が120秒まで生存。平均DPS/到達Lvは双方同じ（SHOT 89.66/11.67、LASER 116.10/11、CHARGE 98.16/10.67、DRILL 116.48/13、DOG 87.57/12、PHANTOM 93.28/9.67）。これは序盤の結果であり30分クリア率ではない。

DOG発射間隔1.12→1.04秒も試したが、初期集団DPSは+3.76%、初期ボスDPSは-5.73%、育成済みボスDPSは-2.39%と混在したため採用しなかった。上の表とfinal原データは短縮を含まない。

## 回帰と再実行

`tests/combat-quality.test.mjs`の9項目は、弾枠満杯・停止/移動・ビルド再計算・追撃の一度発射・NOVA例外・帰還骨の会心/ボス補正・実衝突での二重加算防止・接触のボス補正を検証する。旧版に同じテストをかけると7失敗/2成功、修正版は9成功。NOVA例外の2項目は既存動作の対照。従来のチャージ保持テストも維持。

ブラウザ回帰には、実際に移動しながら弾枠を満杯にし、ビルド再計算後もチャージを保持し、枠解放で発射するテストを追加。従来の最大5ファントム＋25ダーツ＋235通常敵、複合レイド/大ボスの1倍・2倍テストも実行対象。既存CIで15分/30分進行、20シードの通常/チャレンジ5機体比較、性能計測も行う。
