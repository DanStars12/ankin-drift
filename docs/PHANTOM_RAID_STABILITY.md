# ファントム大量展開時の安定性と負荷

ダーツの広範囲索敵を毎フレームから60〜75ms間隔へ分散。移動、射撃間隔、弾の当たり判定は毎フレームの処理を維持する。撃破・回収済み・一時無敵等の無効な標的は即座に破棄し、新規レリックは通常標的のキャッシュを待たずに優先する。標的リセットは主機だけでなく全ダーツにも適用する。

到達不能XPの一時除外・経験値運搬、味方分離、主機のみの属性付与、最終ボス保護、障害物判定と各キュー上限を維持する。ロジック回帰に索敵回数と即時失効/レリック切替を追加。

最大5ファントム・25ダーツ・Lv30・通常敵240体と中/大ボスを置き、実際の複合レイド（群れ・ワープ・障害壁）を1倍/2倍で動かすブラウザ負荷検証へ拡張。描画・攻撃の継続、実行エラー0、キュー上限を確認し、フレーム時間を記録する。合成ロジック比較は400敵・5ゲーム秒で基準コードと同じ乱数/武装を使い、索敵回数とダメージを比較する。合成CPU時間をスマホのFPS改善率とは解釈しない。

スマホでは選択画面の数字キー/R/B表示、PAD案内、オプション内のキーボード/PAD設定説明と欄、タイトルのキー案内を省く。タッチ操作の説明とスキル詳細は維持。PCモードには従来の設定・案内を表示する。

高負荷時と軽い演出設定では、ファントムの刃・レベル文字の高コストな影ぼかしだけを省く。刃の形・残像・ヒット判定・レベル文字は維持する。
