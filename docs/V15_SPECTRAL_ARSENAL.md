# ANKIN DRIFT v15.0 — SPECTRAL ARSENAL

対象は通常モードのPHANTOM。PR #81の標的停止修正・序盤バランス調整を含む。恒久セーブの形式・キー、CO-OPは変更しない。

## 単体で完成するレリック

ファントム用10種類を改修。進化合成素材は追加しない。取得は従来どおり各1回。アストラルコアのID ph_astralCoreを保ち、効果と名称をアストラル・ブレードへ変更した。

| レリック | v15の効果 |
|---|---|
| 幽魂の契約 | 常時：HPが減るほど全機のブレード威力上昇。瀕死で最大+75%。 |
| 銀の誓約 | 同じ敵への連続斬撃で威力+8%ずつ、最大+80%。標的を変えると解除。 |
| 魂の輪廻 | 経験値回収後4秒、全機のブレード威力+40%。回収で時間を更新。 |
| ソウル・エグゼキューター | HP40%未満の敵へブレード威力+70%。斬撃で倒すと周囲へ処刑波。 |
| 銀影の残響 | 通常斬撃3回ごとに、威力65%の残響斬撃を2回追加。 |
| アストラル・ブレード | ゴースト本体も近くの敵へ無属性の白刃を振る。主機の70%威力、Lv10で110%。 |
| ミラー・ダーツ | ショット型の弾が画面端で2回反射し、敵を2体まで貫通する。 |
| クロノ・ニードル | チャージ型が貫通彗星を3連射。本弾の0.18秒・0.36秒後に威力75%の追撃。 |
| アストラル・ハーベスト | フォロー型の移動速度2倍、回収経験値を1.6倍に。ゴーストの経験値補正も適用。 |
| 白刃の蓄電器 | ブレード命中でゴーストのシールド+4。0.25秒に1回、白い護符が輝く。 |

ゴーストの自衛斬撃は本体座標から発生し、主機の威力・攻撃速度・射程・会心を参照する。属性攻撃や残響、連続追撃は複製しない。通常の障壁と最終ボスの装甲保護を尊重する。銀の誓約の連続攻撃数は本体と各ファントムで独立し、標的変更時に解除する。処刑波は半径105・ブレード基準威力50%・最大12体・0.45秒の全機共通待機で、波から波は発動しない。

## ユニークの攻撃変化と指定機体追加

レーザー・チャージ・フォロー用のユニークを3種類追加。既存4種も強化した。

| ユニーク | v15の効果 |
|---|---|
| ダーツ・ソヴリン | 取得時：全5型を各1機追加。出撃時間+8秒。出撃時、ゴースト周囲に白刃波。 |
| プリズム・ダーツ | 取得時：ショット型+1。全ショット型が、同威力の3方向ショットを放つ。 |
| 白刃ゼニス | 通常斬撃3回ごとに、威力120%の交差斬撃を2回追加。追加斬撃からは再発動しない。 |
| フェニックス・レスキュー | 取得時：サポート型+1。バリア耐久・回復量+100%。破壊から2秒で復旧し、周囲の敵弾を消す。 |
| ヘリックス・レイ | 取得時：レーザー型+1。全レーザー型の射程2倍、最大3体を同時照射。 |
| スターゲイザー・レール | 取得時：チャージ型+1。蓄積効率+60%、最大チャージで3方向へ貫通彗星。 |
| ソウル・クーリエ | 取得時：フォロー型+1。移動速度2.5倍、周囲120の経験値を吸引し、回収経験値倍率+0.3。 |

通常枠は最大12。指定型ユニーク5種は各1枠、ソヴリンは各型1機ずつの5枠を別枠で追加し、全取得時は最大22機となる。通常枠が埋まっていても対応タイプの+1を失わない。ダーツ未取得でも指定型ユニークから出撃できる。通常出撃カードは5機未満なら未所持タイプを優先し、5機以上の追加は全タイプからランダム。出撃中の取得ならその場で追加し、待機中なら次回出撃から参加する。

クロノ・ニードルとスターゲイザー・レールの併用では3方向×本弾と追撃2回＝9発。追撃からは再発動しない。プリズムの3方向弾は各100%威力で、ミラー併用時は敵2体を貫通して3体目で消える。フォローの経験値倍率は通常1.2、ハーベストで1.6、クーリエでさらに+0.3。その後にゴーストのEXP補正を乗算し、回復アイテムは収集しない。

## 表示と検証

タイトル、メニュー、図鑑、アーカイブ見出し、マニフェスト、性能レポート、Service Worker登録とキャッシュをv15.0へ統一。カードの説明は取得時の追加機体・発動条件・対象を明記し、同じ定義を図鑑と選択画面で使う。ファントムのブレードタグが風の旋回刃を説明していた問題も修正。

回帰テストに、指定型追加・22機上限・再構築時の非増殖・本体斬撃の威力/属性/障壁/装甲・標的変更・3体貫通・分岐レーザー・9発貫通彗星・支援バリア復旧・経験値の一度だけの回収・追撃非再帰を追加。PC/スマホの実ブラウザでは、長いユニーク説明の表示、12機取得後の実カード選択、本体斬撃のダメージと画面表示も確認する。

高負荷のエンジン検証と、同じ検証AIでの旧版/候補の通常30分進行をdocs/qa/phantom-v15-*へ記録する。ロジック検証からFPSや実プレイヤー勝率は断定しない。
