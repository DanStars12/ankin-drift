# PCのPAD操作と操作設定

PCのGamepad API標準配置を使用。PS系・Xbox系のボタン名を併記する。ブラウザがPADを認識するまで接続後に一度ボタンを押す。実機のUSB/Bluetoothやブラウザ固有のマッピングは実機確認が必要。

| 操作 | キーボード初期値 | PAD初期値 |
|---|---|---|
| 移動・メニュー移動 | WASD / 矢印 | 左スティック / 十字キー |
| 決定 | Enter | ○ / B |
| ダッシュ・メニューで戻る | Space・Escape | × / A |
| NOVA | E | □ / X |
| スキル詳細 | I | △ / Y |
| 一時停止 | P | OPTIONS / Menu |
| BUILD LAB | B | SHARE / View |
| 強化ストック | L | R1 |
| 再抽選 | R | L2 |

OPTIONSの操作設定でキー・ボタン・十字キーを変更し、スティックの遊び（10〜50%）を調整できる。左スティック方向は固定。変更待ちでは戦闘・メニュー操作を発火しない。同じ場面で競合する割当は入れ替え、設定をローカル保存する。初期配置への復元、変更待ちの取消を用意。ESCは変更待ちを取り消す。1〜4の直接スキル取得とTABの標準フォーカス移動も維持。

メニューは可視・有効な項目へ幾何学的にフォーカスを移動し、スクロール追従と明るい選択枠を表示。スキルは左右で順に選択し、名前と全文を読み出し欄へ表示。詳細ボタンで既存の合成/シナジー/タグ情報を中央に表示する。詳細内でも移動/決定を使え、右スティックでスクロールできる。戻る操作は詳細を閉じ、元のカードへ戻す。カードの取得は決定操作だけで実行する。

切断・非表示・フォーカス喪失では移動を解除して一時停止。画面遷移、再接続、復帰時はPADの全ボタンと移動がいったんニュートラルになるまで再入力を許可しない。長押し確認による連続取得を防ぐ。PADとキーボード入力は正規化し、斜め移動の速度が増えない。スマホの既存タッチ入力とセーブデータは維持。

検証: 純粋ロジック（初期配置、遊び、壊れた保存値、競合入替、矢印副割当）とGamepad APIを模擬した実ブラウザ（タイトル/設定、移動/ダッシュ/NOVA/切断、詳細/スクロール/誤取得、キー・PAD割当の保存と旧割当無効化）。物理PADの実機検証とは区別する。
