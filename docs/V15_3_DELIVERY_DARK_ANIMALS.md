# ANKIN DRIFT v15.3 — 経験値運搬・回復リンク・闇アニマル

基点 main cf94b1b。通常モードのPHANTOM/DARK/DOGを対象とし、セーブ形式・キー、CO-OPは維持する。

## ファントムダーツ

- ミラー・ダーツ取得時はショット型+1、クロノ・ニードルはチャージ型+1、アストラル・ハーベストはフォロー型+1。通常12枠・ユニーク10枠にレリック3枠を加え、全取得時は25機。対応型は未所持でも追加するが、ダーツ系レリックの抽選にはダーツを1機以上所持する必要がある。
- フォロー型が経験値を取るとフィールドから取り除き、各機の貨物に格納する。この時点ではゴーストの経験値・NOVAチャージは増えない。出撃終了時に一度だけまとめて届ける。取得時のフォロー倍率を貨物へ反映し、納品時にゴーストの経験値倍率とNOVA獲得補正を適用する。
- 待機・再出撃では前回の貨物を持ち越さず、ビルド再構築では出撃中の貨物・残り時間・位置を保存する。回復アイテムは運搬も吸引もしない。
- フォロー型が実際に移動した間は、取得済みのソウルリレー/魂の輪廻/ソウルドライブによる回収後のブレード強化を更新できる。経験値を架空に加算したり、未取得の効果を解放したりしない。
- 移動3秒ごとに25%の確率で回復アイテムを落とす。全フォロー型で6秒の共通投下待機を持ち、停止中・待機中は落とさない。回復アイテムはゴーストが拾う。
- サポート型は距離150以内かつ壁に遮られないゴーストへ緑の線を繋ぎ、その間HPを回復する。防御バリアの耐久・敵弾防御・接触ダメージ・復旧は維持するが、バリア自体は回復効果を持たない。バリア破壊中でもリンク回復は可能。
- ファントムNOVAに、ゴーストを中心とした範囲ダメージを追加。NOVAの実効威力と範囲を使用し、通常の障壁を貫通。部位破壊前の最終ボス本体は対象にせず、同じ敵へ1回の発動で重複命中しない。範囲表示も実際の上限へ合わせる。

## ハッキングとDOGの闇

プログラムコントロールの生きている領域内で倒れた通常敵を、攻撃手段にかかわらずハッキング候補にする。判定は撃破処理へ統合し、回転している四角形と敵の実座標を照合する。重なった領域でも同じ敵の抽選は1回。味方化確率30%、同時3体、寿命5秒、ボス/レリック対象外を維持する。味方は敵/報酬プールとは別で、同じ死体を再変換しない。

DOGの基本コウモリは「いたずら・コウモリ」、共通闇強化6種類はDOG専用の明るい名前とアイコンへ置き換える。通常機体の名前・IDは維持する。DOGの関連シナジーも新しい専用IDに対応する。コウモリとくまさんの攻撃にはDOGのアニマル威力補正も適用する。

コウモリは攻撃時に飛び出し、紫の恐怖の扇は描画しない。くまさんは設置攻撃の領域に大きく出現する。ゴースト/機体の左右に常駐していた2匹は削除し、攻撃や設置がない時には描画しない。味方化した敵の強調表示は従来どおり共通。

| 対象 | 変異 | 効果と代償 |
|---|---|---|
| 通常機体 | フィアー・エクリプス | 恐怖を全周化、射程20%縮小 |
| 通常機体 | コード・シタデル | 設置範囲1.5倍、発動間隔35%延長 |
| DOG | きらきら・こうもりパレード | コウモリが全方向へ飛び出す、飛距離20%縮小 |
| DOG | くまさんの大きなおうち | くまさんの範囲1.5倍、出現間隔35%延長 |

変異は元の武装取得後に各1回。通常機体用とDOG用は相互に抽選されない。
